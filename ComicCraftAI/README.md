# ComicCraft — AI Comic Story Creator

ComicCraft is a FastAPI + Jinja2 web application that transforms a user's story idea into a five-panel comic.

The application supports:

- AI story outline generation
- AI narration generation
- AI dialogue generation
- AI image generation
- Comic preview
- PDF export
- JSON API
- Local mock mode
- Automated testing

---

Backend:

- Python
- FastAPI
- Uvicorn
- Pydantic

- HTML
- CSS

AI:

- Google Gemini
